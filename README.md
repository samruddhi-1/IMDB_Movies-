The project involved analyzing IMDb movie and director data using SQL. Various SQL queries were performed to retrieve, filter, sort, and summarize movie and director information. Joins and aggregate functions were used to analyze director performance, movie popularity, ratings, and revenue.


# IMDb Movies & Directors SQL Analysis

## Project Overview
This project focuses on analyzing IMDb movie and director data using SQL to explore movie popularity, revenue, ratings, and director performance.

## Project Approach
Used SQL queries to retrieve, filter, sort, and analyze movie and director information. Applied aggregate functions, joins, and grouping to derive meaningful insights.

## Dataset
The project consists of two tables:
- Movies: Movie titles, release dates, popularity, revenue, and average votes.
- Directors: Director IDs, names, and gender.

## Tools Used
- MySQL
- MySQL Workbench

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- LIKE and IN
- COUNT(), MAX(), SUM()
- GROUP BY and LIMIT
- INNER JOIN
- Date filtering

## Key Analysis
1. Total number of movies.
2. Director information and female director count.
3. Top 3 popular movies.
4. Top 3 highest-revenue movies.
5. Highest average-rated movie since 2000.
6. Movies directed by Brenda Chapman.
7. Director with the highest number of movies.
8. Director with the highest total revenue.

## Conclusion
The project provided practical experience in SQL-based data analysis and helped identify patterns in movie popularity, ratings, revenue, and director performance.
